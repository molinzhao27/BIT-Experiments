# Eval-only input ablations (scripts/eval_ablations.py)

Same weights, greedy decoding; only the neural input changes (configs/eval_ablations.yaml, docs/EVAL_ABLATIONS.md). ΔWER = WER(ablation) − WER(none), percentage points, paired trial bootstrap 95% CI. Sound-alike = share of in-dictionary substitutions with phoneme similarity ≥ 0.5, observed / length-matched null. Phon excess = mean phoneme similarity of the substitutions − null (95% CI); vs none = paired change in that excess. One seed per run.
